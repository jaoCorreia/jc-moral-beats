## ⚡ Conceito: Densidade Moral (Moral Density)
Inspirado na crueza e ficção científica distópica da antologia *Love, Death + Robots*, a identidade artística de **JC_MORAL** busca o peso da consciência em frequências sub-graves densas, timbres analógicos cortantes e baterias orgânicas.

### 🎹 Manifesto: 100% Feito à Mão (Zero IA)
- **Composição Humana**: Cada melodia, acorde, progressão harmônica, linha de baixo 808, sintetizador e padrão de bateria é composto manualmente nota por nota.
- **Zero Geração Procedural / Algorítmica**: Nenhuma IA generativa sonora foi utilizada. Arte sonora humana, orgânica e visceral.
- **Identidade Híbrida**: Fusão de Lo-Fi, Cyber Drill, Boombap e síntese analógica com reatividade visual 3D em tempo real.

## 🎧 Modos de Visualização

### 1. Modo Ouvinte / Portfólio (Visitor Mode)
Uma interface limpa e minimalista feita para fãs, ouvintes e parceiros de colaboração:
- **Catálogo de Beats**: Playlist com player contínuo, contador de curtidas (com efeito de corações flutuantes) e barra de progresso.
- **Presets Visuais Automáticos**: Cada beat aciona automaticamente uma combinação exclusiva de cenário 3D, skin de robô e shader ASCII.
- **Bio & Manifesto**: Gaveta lateral com a história de JC_MORAL, arsenal de produção e contatos diretos.
- **Acesso Restrito**: Ícone discreto de cadeado (`🔒`) para login do produtor.

### 2. Painel do Produtor (Dev / Producer Mode)
Liberado através do portal restrito via **Chave Mestra Clearance**:
- **TikTok 9:16 Video Studio**: Alterna o canvas para proporção vertical de celular (720x1280), com overlay de safe-zone do TikTok e botão de **Gravação Direta de Clipes (15s / 30s)** que exporta o vídeo `.webm` pronto com áudio para postar nas redes sociais.
- **Captura de Áudio em Tempo Real**: Sincronização direta com abas do Spotify, YouTube ou fones via `getDisplayMedia` / `AudioContext`.
- **Estúdio de Cenários & Shaders**: Controle manual de 3 cenários 3D (Street Skatepark, Cyber Matrix, Valley 3D), 3 skins de robô (Cytro, KVRC, Hybrid Scratch) e sketches LDR.
- **Janela Flutuante PiP**: Ativa modo Picture-in-Picture que sobrepõe a arte visual no macOS sobre qualquer aplicativo de trabalho.

## 🚀 Como Rodar Localmente

```bash
# 1. Clone o repositório
git clone https://github.com/jaoCorreia/jc-moral-beats.git
cd jc-moral-beats

# 2. Instale as dependências
npm install

# 3. Compile os assets (esbuild bundle)
npm run build

# 4. Inicie o servidor com suporte a streaming de áudio HTTP 206
npm start
```
Acesse em seu navegador: **http://localhost:4321**

## 🛠️ Stack Tecnológica
- **Áudio**: Web Audio API, AnalyserNode FFT de 64 bandas, Synthesizer Polyphonic WebAudio, HTML5 Audio Range Streaming.
- **Gráficos**: Three.js (WebGL 3D), Canvas 2D (ASCII Particle & Glyph Matrix Shaders), CSS Backdrop-filter & Scanlines CRT.
- **Vídeo / Gravação**: Canvas 2D `captureStream()`, Web Audio `MediaStreamAudioDestinationNode`, `MediaRecorder` com exportação automática de vídeo 9:16.
- **Build**: Node.js, `esbuild`, Tailwind CSS.
